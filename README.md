# Stets-Home

## Описание проекта
Проект посвящен системному анализу, проектированию пользовательского опыта и моделированию данных для мобильного приложения **Stets Home**.

Компания Stets создала инновационную технологию программно-аппаратного запуска умных устройств в режиме энергосбережения и выпустила первую умную лампочку с этой функцией. Сторонние приложения для умного дома не поддерживали управление энергосбережением, поэтому потребовалось разработать собственное мобильное приложение для полноценного управления устройствами экосистемы и контроля расхода энергии.

---

## Этапы проекта

### 1. Выявление и анализ требований
- Анализ первичных материалов интервью с заказчиком и конечными пользователями.
- Выделение бизнес-целей, функциональных и нефункциональных требований к системе.
- Построение диаграммы потоков данных (DFD) для отображения взаимодействия мобильного приложения, серверной части и умных устройств.

### 2. Проектирование сценариев и приоритизация (USM & Gherkin)
- Построение карты пользовательских историй со сценариями использования.
- Определение границ и состава минимально жизнеспособного продукта.
- Составление критериев и сценариев приёмки для всех историй MVP на языке Gherkin.

### 3. Моделирование структуры данных
- Разработка логической ER-диаграммы в нотации Crow’s Foot.
- Последовательная нормализация модели данных до третьей нормальной формы.
- Составление словаря данных с описанием элементов: назначение, типы и структуры данных, длина полей и допустимые значения.

### 4. Проектирование интерфейсов и прототипирование
- Разработка диаграммы структуры интерфейсов.
- Создание интерактивного кликабельного прототипа приложения Stets Home в Figma для тестирования ключевых сценариев управления устройствами.

### 5. Контроль качества и презентация проекта
- Разработка Программы и методики испытаний для проверки соответствия системы требованиям перед передачей в разработку.
- Подготовка и запись видеопрезентации с демонстрацией логики решения, архитектуры и работы прототипа.

## Навыки и инструменты

### Навыки:
1. Анализ и структурирование требований из интервью со стейкхолдерами
2. Построение User Story Mapping и выделение границ MVP
3. Описание приёмочных критериев на языке Gherkin
4. Построение диаграмм потоков данных (DFD)
5. Проектирование реляционных моделей данных (ERD в нотации Crow’s Foot)
6. Нормализация баз данных до третьей нормальной формы
7. Разработка словарей данных
8. Проектирование структуры интерфейсов и интерактивное прототипирование в Figma
9. Разработка Программы и методики испытаний

### Инструменты:
- **Моделирование данных и потоков:** Draw.io, нотация Crow’s Foot, DFD
- **Прототипирование:** Figma
- **Требования и сценарии:** Gherkin, Miro, Google Документы

## Выводы по проекту

- **Фокус на ключевом преимуществе:** анализ требований помог вынести уникальную функцию управления энергосбережением в центр пользовательского опыта, обеспечив конкурентное отличие продукта от других систем умного дома.
- **Понятность критериев для разработки:** сценарии приёмки на языке Gherkin сформировали основу для автоматизированного тестирования и прояснили логику работы приложения.
- **Надежная и масштабируемая структура данных:** нормализация ER-модели до 3НФ и составление словаря данных исключили дублирование информации и подготовили базу к подключению новых типов умных устройств без перепроектирования таблиц.
- **Минимизация правок на этапе кода:** схема навигации, кликабельный прототип в Figma и ПМИ позволили протестировать пользовательские пути на ранней стадии разработки.
